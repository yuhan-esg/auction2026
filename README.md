# 연말 나눔 경매

임직원 기부 물품을 실시간으로 경매하는 사이트입니다. Cloudflare Workers와 Durable Objects 위에서 돌아가고, GitHub `main` 브랜치에 올리면 자동으로 배포됩니다.

- **참여자 화면** `/`: 사번 6자리와 휴대폰 번호로 입장 → 물품 목록(실시간 입찰가) → 상세 페이지에서 입찰
- **상세 페이지**: 대표 사진 1장 아래로 상세 사진을 쇼핑몰처럼 길게 나열. PC에서는 오른쪽 입찰 패널(현재가·입찰 입력·입찰 현황)이 스크롤해도 고정되고, 모바일에서는 화면 아래에 현재가와 「입찰하기」 바가 고정됩니다.
- **관리자 화면** `/admin.html`: 지정된 관리자만 접속. 물품 등록·수정·삭제, 대표 사진과 상세 사진(여러 장, 순서 변경), 종료 시각, 낙찰 결과와 연락처, CSV 다운로드, 문자 문구·발송 기록, 개인정보 삭제

> 현재 **문자는 테스트 모드**입니다. 경매가 끝나면 낙찰자별 문자가 만들어지지만 실제로 보내지 않고 관리자 화면 ‘문자 발송’ 탭에 미리보기로만 남습니다. 솔라피 준비가 끝나면 [문자 실제 발송 켜기](#문자-실제-발송-켜기)를 따라 주세요.

## 동작 방식

| 항목 | 방식 |
|---|---|
| 입장 | 사번 6자리, 휴대폰 번호(010…), 개인정보 동의 → 형식만 맞으면 입장 |
| 로그인 유지 | 같은 기기·같은 브라우저라면 창이나 브라우저를 껐다 켜도 다시 로그인할 필요 없음. 로그아웃을 누르거나, 브라우저 데이터를 지우거나, 관리자가 ‘휴대폰 번호 전체 삭제’를 하면 다시 로그인 |
| 관리자 | `ADMIN_USERS`에 등록된 **사번 + 휴대폰 번호가 둘 다 맞는** 사람만. 경매장에서 같은 정보로 로그인하면 위쪽에 「관리자」 버튼이 생기고, 관리자 화면도 따로 로그인할 필요 없음 |
| 실시간 | WebSocket으로 모든 접속자에게 입찰가를 즉시 전송, 끊기면 자동 재연결 |
| 입찰 규칙 | 최소 입찰가 = 현재 최고가 + 입찰 단위 (첫 입찰은 시작가부터). 같은 금액이 동시에 들어오면 먼저 도착한 한 건만 인정. 본인이 이미 최고가면 입찰 불가. 1초에 1번까지 |
| 마감 | 서버 시각 기준. 종료 시각이 되면 서버가 자동으로 낙찰을 확정하고, 화면에 「낙찰완료」(입찰 없으면 「유찰」)가 표시되며 입찰이 막힘 |
| 낙찰 문자 | 확정 즉시 낙찰자 번호로 자동 발송 (테스트 모드에서는 기록만) |
| 개인정보 | 공개 화면에는 사번을 `12**56`처럼 가려서 표시하고, 휴대폰 번호는 관리자만 볼 수 있음 |
| 마감 연장 (선택) | `ANTI_SNIPE_SECONDS`를 예: `60`으로 하면 마감 60초 안에 입찰이 들어올 때 마감이 60초 늘어남 |

## 폴더 구조

```
├─ src/
│  ├─ index.js        Worker 진입점 (/api → Durable Object, 나머지 → 정적 파일)
│  ├─ auction.js      경매 서버 전체 (DB, 입찰, 실시간, 마감 알람, 관리자 API)
│  └─ sms.js          문자 발송 (테스트 모드 / 솔라피)
├─ public/            화면 (index.html, admin.html, app.js, admin.js, common.js, style.css)
├─ test/              테스트 (npm test) – 배포에는 포함되지 않음
├─ wrangler.jsonc     Cloudflare 설정
└─ .github/workflows/deploy.yml   main에 push하면 테스트 후 자동 배포
```

## 처음 배포하기 (약 15분)

### 1. GitHub에 올리기
1. GitHub에서 새 저장소를 만듭니다. 회사 내부용이므로 **Private** 권장.
2. 이 폴더 내용을 그대로 올립니다.
   ```bash
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<조직>/<저장소>.git
   git push -u origin main
   ```
   첫 push 때는 아직 비밀값이 없어서 Actions가 실패합니다. 2~3단계를 마친 뒤 다시 실행하면 됩니다.

### 2. Cloudflare API 토큰 만들기
1. Cloudflare 대시보드 → 오른쪽 위 프로필 → **My Profile → API Tokens → Create Token**
2. **Edit Cloudflare Workers** 템플릿을 고르고, 계정(Account)을 회사 계정으로 지정해 만듭니다.
3. 대시보드 Workers 화면 오른쪽에 있는 **Account ID**도 복사해 둡니다.

### 3. GitHub 저장소에 비밀값 넣기
저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 2단계에서 만든 토큰 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID |

그다음 **Actions 탭 → Deploy to Cloudflare → Run workflow**로 배포합니다. 성공하면 `https://year-end-auction.<계정>.workers.dev` 주소가 생깁니다.

### 4. 관리자 명단 등록 (필수)
Cloudflare 대시보드 → **Workers & Pages → year-end-auction → Settings → Variables and Secrets → Add**
- Type: **Secret**, Name: `ADMIN_USERS`
- Value: `사번:휴대폰번호`를 쉼표로 이어서 한 줄로. 예) `123456:01012345678,654321:01098765432`

휴대폰 번호가 GitHub에 남지 않도록 코드가 아니라 Cloudflare 비밀값으로 저장합니다. 관리자를 바꾸려면 이 값만 고치면 되고, 명단에서 빠진 사람은 즉시 관리자 권한이 없어집니다.

또는 터미널에서 `npx wrangler secret put ADMIN_USERS`

### 5. 물품 등록 & 테스트
0. 화면을 먼저 보고 싶으면 관리자 → 데이터 관리 → **샘플 물품 넣기**를 누르세요. [샘플] 물품 8개가 사진·가상 입찰과 함께 들어가고, 샘플은 문자가 절대 나가지 않습니다. 확인 후 **샘플만 삭제**.
1. `https://…/admin.html`에서 관리자 사번·번호로 들어가 물품을 등록합니다. 상세 사진은 여러 장을 한 번에 고를 수 있고, ▲▼로 순서를 바꿀 수 있습니다(사진은 자동으로 줄여서 저장). 종료 시각을 1~2분 뒤로 잡고 동료와 휴대폰으로 입찰해 보세요.
2. 마감 후 ‘낙찰 결과’와 ‘문자 발송’ 탭에 낙찰자, 연락처, 문자 미리보기가 생기는지 확인합니다.
3. 테스트가 끝나면 ‘데이터 관리 → 전체 초기화’ 후 실제 물품을 등록합니다.

### (선택) 회사 도메인 연결
Cloudflare에 회사 도메인이 있다면 Worker → **Settings → Domains & Routes → Add → Custom domain**에서 예: `auction.회사도메인.co.kr`을 연결합니다.

### (선택) 사내 인원만 접속하게 하기
형식만 맞으면 누구나 입장할 수 있으므로 주소가 밖으로 퍼지지 않게 주의하세요. 더 막고 싶다면 Cloudflare **Zero Trust → Access**에서 회사 이메일 인증을 붙일 수 있습니다(50명까지 무료).

## 문자 실제 발송 켜기

솔라피 준비 체크리스트:
1. 솔라피 가입 후 **발신번호 등록**. 회사 대표번호 등을 쓰려면 통신서비스 이용증명원 같은 서류 심사가 있어 며칠 걸릴 수 있습니다.
2. 잔액 충전
3. **API Key / API Secret** 발급. IP 제한(허용 IP) 설정은 꺼 두세요. Cloudflare Workers는 고정 IP가 없습니다.

그다음 Cloudflare 대시보드 → Worker → **Settings → Variables and Secrets**에 아래 3개를 **Secret**으로 추가합니다.

| 이름 | 값 |
|---|---|
| `SOLAPI_API_KEY` | API Key |
| `SOLAPI_API_SECRET` | API Secret |
| `SMS_FROM` | 등록한 발신번호 (예: `0212345678`) |

마지막으로 `wrangler.jsonc`에서 `"SMS_MODE": "dry-run"`을 `"SMS_MODE": "live"`로 바꿔 커밋하고 push하면 배포됩니다.

**실제 행사 전에 꼭** 종료 시각이 1분 뒤인 테스트 물품을 하나 만들고 본인 번호로 낙찰받아, 문자가 오는지와 ‘문자 발송’ 탭에 「발송완료」가 찍히는지 확인하세요. 실패하면 상태에 마우스를 올려 오류 내용을 볼 수 있습니다. 관리자 화면 상단의 노란 띠가 빨간 띠(“실제 발송 모드”)로 바뀌었는지도 확인하세요.

> 솔라피 API 방식이 바뀌었을 수 있으니, 실제로 켜기 전에 [솔라피 개발 문서](https://solapi.com/developers)의 메시지 발송 API와 `src/sms.js`가 맞는지 한 번 확인해 주세요.

문자 문구는 관리자 화면 ‘문자 발송’ 탭에서 바꿀 수 있고 `{행사명} {번호} {물품명} {낙찰가} {사번}`을 넣을 수 있습니다. 한글 45자(90byte)를 넘으면 장문(LMS) 요금이 적용됩니다.

## 행사 후 정리
1. 관리자 → 낙찰 결과에서 **낙찰 결과 / 전체 입찰 내역 / 참여자 명단 CSV**를 받아 보관합니다 (엑셀에서 바로 열림).
2. 관리자 → 데이터 관리 → **휴대폰 번호 전체 삭제**를 누릅니다. 동의 문구에 안내 후 삭제한다고 적혀 있습니다.

## 로컬에서 고치고 확인하기
```bash
npm install
cp .dev.vars.example .dev.vars   # ADMIN_USERS 수정
npm run dev                      # http://localhost:8787
npm test                         # 서버 로직 테스트
```

## 자주 묻는 것
- **종료 시각 기준은?** 관리자가 입력한 시각(브라우저 시간대, 한국이면 KST)이고, 마감 판정은 서버 시계로 합니다.
- **잘못 누른 큰 금액 입찰은?** 관리자 → 물품 관리 → 입찰내역에서 마감 전까지 취소할 수 있습니다. 참여자 화면에서도 현재가보다 5배 이상 크면 한 번 더 확인합니다.
- **마감된 물품을 다시 열고 싶다면?** 종료 시각을 미래로 고치면 다시 진행중이 됩니다.
- **비용은?** 사내 행사 규모(수백 명, 수천 건 입찰)는 Cloudflare Workers 무료 플랜 한도 안입니다. 문자는 솔라피에 건당 요금이 붙습니다.
